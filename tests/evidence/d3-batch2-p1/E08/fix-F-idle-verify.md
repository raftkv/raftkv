### 5.3 修复F代码变更

**文件**：`grpc_server.go`，`StartReconnectLoop`函数

```go
// 修复前（误判Idle为失败态）：
if state == connectivity.TransientFailure || state == connectivity.Idle || state == connectivity.Shutdown {

// 修复后（仅真失败态才重连）：
if state == connectivity.TransientFailure || state == connectivity.Shutdown {
```

**原理**：`grpc.NewClient()`是惰性连接，返回`connectivity.Idle`是正常初始态，不是失败。修复前把Idle误判为失败，导致每8s无条件重建所有peer连接——新连接又是Idle，形成无限循环。修复后健康Idle连接不碰，仅`TransientFailure`/`Shutdown`才重连。
